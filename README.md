# Gestión de vehículos (PWA)

Inventario modular para compra, mejora y venta de vehículos. Funciona sin servidor; los datos se guardan en el navegador.

## Publicar en GitHub Pages
1. Sube todos estos archivos a la raíz de un repositorio.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. Abre el enlace `https://TU-USUARIO.github.io/TU-REPO/` y, en el teléfono, "Agregar a pantalla de inicio".

## Módulos
Núcleo: Inicio, Inventario, Ficha del vehículo, Configuración.
Se activan en Configuración: Finanzas, Compras. El resto aparece como "Próximamente".

## Importante
Los datos están en el navegador de cada dispositivo. Exporta un respaldo desde Configuración con frecuencia.
